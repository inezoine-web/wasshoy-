# Research reports

AIエージェントによる地域・テーマ別調査レポートを保存します。

推奨ファイル名:

`YYYY-MM-DD-<scope>.md`

例:

- `2026-08-31-ibaraki-south.md`
- `2026-09-01-kanuma.md`
- `2026-09-05-fire-festivals.md`

各レポートは対応するGitHub Issue番号を冒頭に記載してください。

## 推奨構成

1. 調査対象
2. 調査日・対応Issue
3. 探索方法
4. 新規発見
5. 既存データの更新
6. 注目した祭り
7. candidate / 未確認事項
8. 情報源間の食い違い
9. 網羅性に関する注意
10. 次回調査案

レポートは「調べた結果」だけでなく、**どこをどう探したか、何が見つからなかったか**も残してください。後から探索戦略そのものを改善するためのログとして使います。
