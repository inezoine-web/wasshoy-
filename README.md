# Wasshoy!

日本各地に埋もれている祭り・祭礼・伝統行事を、AIエージェントによる調査で発見・整理する実験プロジェクトです。

## 最初の目的

「有名な祭りを検索する」のではなく、**名前すら知らない近隣・地域の祭りを発見可能にする**ことを目指します。

まずはアプリや専用クローラーを作りません。GitHub Issueを調査指示書として使い、AIエージェントがWebを調査し、根拠を確認し、構造化データと調査レポートを更新する運用がどこまで成立するかを検証します。

## 基本フロー

1. Issueで対象地域・テーマ・再調査条件を指定する
2. `AGENTS.md` の調査ルールに従って候補を探索する
3. 祭り名を発見したら二次検索して裏取り・深掘りする
4. `data/festivals.json` に確認できた情報を追加・更新する
5. `reports/` に調査範囲、発見、未解決事項、探索漏れの可能性を記録する
6. 出典URLと確認日を必ず残す

## ディレクトリ

- `AGENTS.md` — AIエージェント向け調査・編集ルール
- `data/festivals.json` — 祭りの構造化データ
- `data/schema.md` — データ項目と記録方針
- `reports/` — Issue単位・地域単位の調査レポート

## 実験で見たいこと

- 自治体サイトを起点に、既知の祭りへ自力で到達できるか
- 一次情報が薄い場合、適切な追加検索で情報を補完できるか
- 同じ祭りの別名・重複を適切に扱えるか
- AIが根拠のない歴史・規模・日程を補完しないか
- 人間が知らなかった「なんだこの祭り!?」を発見できるか

専用コードは、エージェント運用で実際のボトルネックが見えてから必要な部分だけ追加します。
