## これで測れること / 測れないこと

**測れること**

- `gold.tsv` の再現率 — ここを落としたら明確な後退
- `snapshot.json` 225件の再現率 — 旧手法に対する回帰の下限
- 1件も取れなかった市町村の数
- snapshotに無い新規候補の件数

**測れないこと（重要）**

- **網羅性。** snapshot自体が不完全である。由来レポート§7が、鹿島神宮の主要祭礼（祭頭祭・式年大祭）、潮来市・石岡市・東海村等の薄さ、県指定無形民俗文化財一覧の2ページ目以降、地区・町会レベルの祭り全般が未探索であることを明記している。**再現率100%でも「茨城県を調べ終えた」ことにはならない。**
- **precision。** snapshotに無い候補が誤りとは限らない（旧手法の漏れである可能性が高い）。機械的に precision は計算できないため、新規候補からサンプル30件を目視して内訳を報告する運用とする。
- **`candidate` の正しさ。** snapshot の214件は本文未確認であり、名称・所在・日付に誤りを含む。レポート§5が実際に混入した誤り（自治体をまたぐ誤配置、所在未確認の神社、季節と矛盾する日付）を列挙している。**snapshot は「正解」ではなく「旧手法の出力」である。**

## リーク防止

`snapshot.json` と `gold.tsv`、および `data/festivals.json` は、**パイプラインの S1〜S4（発見・抽出・正規化・AI判定）から読んではならない。**

茨城県だけ既存データが存在するため、それを入力にすると茨城でのスコアが不当に高くなり、データのない46都道府県で再現しない。既存データを参照してよいのは `merge.py`（S5、重複回避）と `evaluate.py`（S6、採点）だけである。

この分離は機械的に確認できる:

```bash
grep -rn "open(\|read_text(\|json.load" pipeline/*.py | grep -i "festivals\|snapshot\|gold"
```

ファイルを実際に開いている箇所だけを見る (説明コメントに拾われないため)。
`merge.py` と `evaluate.py` 以外がヒットしたらリークである。
