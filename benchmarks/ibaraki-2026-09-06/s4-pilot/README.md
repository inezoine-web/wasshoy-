# S4 パイロット（1バッチ・120行）

`s4_prepare.py` が出したバッチと、それに対する判定の**実例**。
他のAIが S4 を回すときの参照用に残してある。判定は絶対の正解ではなく、
「この粒度で、この判断を、この形式で返す」という見本として読むこと。

| file | 内容 |
| --- | --- |
| `s4_batch_001.tsv` | AIに渡した入力（120行、19.4KB） |
| `s4_verdict_001.tsv` | 返した判定（120行、3.3KB） |

## 実測

| | |
| --- | --- |
| 入力 | 19.4KB / 120行 = **1行あたり約160バイト（約90トークン）** |
| 出力 | 3.3KB / 120行 |
| 1バッチの往復 | 約11,000トークン |
| 茨城県 全1595行の見込み | **約15万トークン** |

旧手法は同じ県で約55万トークンを使い `verified` 0件だった。

このバッチで確定できたもの:

  日立風流物→日立市、綱火→つくばみらい市、潮来ばやし→潮来市、

  **旧手法が「所在未確認のため未登録」として落とした19件（前回レポート §7-7）に相当する。**
- **別名統合 20件** — 「茨城県指定無形民俗文化財「潮来ばやし」」→「潮来ばやし」、
  「綱火 つなび」「綱火保存連合会」→「綱火」など
- **slug 16件** — 読みをかなで返し、ローマ字化は `romaji.py` が行った

## 判断の指針（この実例で採った基準）

- **団体名は残す**が `reason=organization` を付ける。「井草大杉囃子保存会」は
  行事そのものではないが、行事の存在を示す。S5 で `保存会` を落として名称を整える想定
- **他県の事例紹介は落とす**。「京都紙園祭の山鉾行事」は県教委サイトの
  ユネスコ登録の説明に出てくるもので、茨城の行事ではない
- **一般語・断片は落とす**。「太鼓」「踊り」「お囃子」「感謝祭でやってみたいこと」
- **子育て支援・学校行事は落とす**。「こども夏まつり」「茨城県高等学校総合文化祭」
- **商業イベントは落とす**（AGENTS.md §2）。「つくばラーメンフェスタ」
- **どちらとも言えないものは `unsure`**。「祇園祭」は所在も主体も分からず、
  どの祇園祭か特定できない

## 既知の弱点

- 名称に「県指定 富田のささら 所在地 石岡市国府5」のような一覧表の断片が
  残る。keep にはしたが、S5 で名称の整形が要る
- `reading` を返せたのは keep 62件中16件。漢字の読みは自信がないものが多く、
  推測で埋めていない。slug の PENDING は S5 以降も残る
