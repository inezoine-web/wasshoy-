# S4 判定の実例（茨城県 全14バッチ・1595行）

`s4_prepare.py` が出したバッチと、それに対する判定の**実例**。
他のAIが S4 を回すときの参照用に残してある。判定は絶対の正解ではなく、
「この粒度で、この判断を、この形式で返す」という見本として読むこと。

茨城県の全1595行を14バッチで判定した結果を全部置いてある
（`s4_batch_001.tsv` は入力の例、`s4_verdict_001.tsv`〜`014.tsv` が判定）。

| file | 内容 |
| --- | --- |
| `s4_batch_001.tsv` | AIに渡した入力の例（120行、19.4KB） |
| `s4_verdict_001.tsv` 〜 `_014.tsv` | 返した判定（計1595行） |

## 実測

| | |
| --- | --- |
| 入力 | 19.4KB / 120行 = **1行あたり約160バイト（約90トークン）** |
| 出力 | 3.3KB / 120行 |
| 1バッチの往復 | 約11,000トークン |
| 茨城県 全1595行（14バッチ） | **約15万トークン** |

旧手法は同じ県で約55万トークンを使い `verified` 0件だった。

## 全1595行の内訳

| verdict | 件数 |
| --- | --- |
| keep | **871** |
| drop | 723 |
| unsure | 1 |

ノイズ率45%は、S2の抽出結果を無作為30件目視したときの43%とほぼ一致する。

drop の理由: 断片 339 / 一般語 299 / 団体名 39 / 他県・他市の事例 25 / 商業 12 / 会場名のみ 9。

**14バッチすべて `s4_apply.py --strict` を一発で通過した**（id の過不足なし、
別名の循環なし、読みはすべてかな、slug の重複なし）。

確定できたもの: 別名統合 267件、所在市町村 25件、slug 226件。

最初のバッチ（`(県全域)` を含む120行）で確定できたもの:

- **所在市町村 25件** — 県単位レンズで拾った `(県全域)` の文化財に所在を与えた。
  日立風流物→日立市、綱火→つくばみらい市、潮来ばやし→潮来市、
  浅川ささら→大子町、富田のささら→石岡市、水戸大神楽→水戸市 など。
  **旧手法が「所在未確認のため未登録」として落とした19件（前回レポート §7-7）に相当する。**
- **別名統合 20件** — 「茨城県指定無形民俗文化財「潮来ばやし」」→「潮来ばやし」、
  「綱火 つなび」「綱火保存連合会」→「綱火」など
- **slug 16件** — 読みをかなで返し、ローマ字化は `romaji.py` が行った

## 判断の指針（この実例で採った基準）

- **団体名は残す**が `reason=organization` を付ける。「井草大杉囃子保存会」は
  行事そのものではないが、行事の存在を示す。S5 で `保存会` を落として名称を整える想定
- **他県の事例紹介は落とす**。「京都紙園祭の山鉾行事」は県教委サイトの
  ユネスコ登録の説明に出てくるもので、茨城の行事ではない
- **一般語・断片は落とす**。「太鼓」「踊り」「お囃子」「感謝祭でやってみたいこと」
- **子育て支援・学校行事は落とす**。「こども夏まつり」「茨城県高等学校総合文化祭」
- **商業イベントは落とす**（AGENTS.md §2）。「つくばラーメンフェスタ」
- **どちらとも言えないものは `unsure`**。「祇園祭」は所在も主体も分からず、
  どの祇園祭か特定できない

## ベンチマークへの影響

**出力の45%を落として、gold は1件も失わず、snapshot 一致は2件しか減らなかった。**

| | S3（判定前） | S4（判定後） |
| --- | --- | --- |
| 出力 | 1595件 | 871件 |
| gold | 23/34 | **23/34** |
| snapshot 再現 | 150/225 | 148/225 |

減った2件は調べると照合経路の弱さによる見かけの損失だった。
「取手ひなまつり」は根拠URLのみでの一致（drop したノイズ行がたまたま
同じページを引用していただけ）、「神幸祭」は石岡市の別の神幸祭への誤一致。
**実質的な取りこぼしはゼロ。**

## 既知の弱点

- 名称に「県指定 富田のささら 所在地 石岡市国府5」のような一覧表の断片が
  残る。keep にはしたが、S5 で名称の整形が要る
- `reading` を返せたのは keep 871件中226件。漢字の読みは自信がないものが多く、
  推測で埋めていない。slug の PENDING は S5 以降も残る
- 「保存会」を keep（`reason=organization`）にした28件は議論の余地がある。
  行事そのものではないが行事の存在を示す。S5 で扱いを決める
- `(県全域)` のまま所在を与えられなかった行が18件残る
